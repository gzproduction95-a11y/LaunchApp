# Contributing / 贡献指南

English: Keep changes narrowly scoped, write or update a meaningful test before changing behaviour, and update bilingual documentation when a user-visible rule changes. Do not add MatrixOS firmware source, compiled firmware, Live Sets, User Library files, device logs, or generated ZIP files to this repository.

中文：保持修改范围明确；改变行为前先编写或更新有意义的测试；用户可见规则变化时更新中英对照文档。不要向本仓库加入 MatrixOS 固件源码、已编译固件、Live Set、User Library 文件、设备日志或生成的 ZIP 文件。
