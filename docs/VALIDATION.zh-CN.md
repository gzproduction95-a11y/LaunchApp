# 验收说明

## 证据等级

- **自动化：** 使用 MatrixOS 与 Live API 替身运行 CPython 测试。
- **Live：** 在 Ableton Live 中加载 Remote Script，并在可丢弃或已备份的 Set 中检查操作。
- **实机：** 用户观察 Mystrix 灯光、USB MIDI、响应时序和稳定性。

通过某一等级不能自动证明更高一级通过。

## V2.2.2 发布验证记录

- 自动化：发布工作区中的 187 项测试通过。
- 压缩包：V2.2.2 设备端/电脑端配套压缩包，初始包间隔为 40 毫秒。
- 实机验收：用户将配套压缩包安装到 Mystrix Pro，并在 Ableton Live 12.4.6 中测试。控制器可用；用户反馈首次录音倒数灯效和 Fn 翻页响应有所改善，最近一轮未观察到明显问题。
- 限制：人工灯光观察属于定性结果，并非仪器测得的延迟或色度报告。此结果不代表其他固件、Live 或硬件版本均已验证。

## 重复关键检查

1. 确认设备端和电脑端都来自同一 V2.2.2 压缩包，并确认 Live 显示协议 v11 已连接。
2. 在隔离 Set 中先核对 Pad 与 Track/Scene 的位置，再启动 Clip。
3. 走带停止时 Arm 一条轨道并触发第一个空格，观察录音倒数提示及其转为录音灯效的时机。
4. 多次测试 Fn 单击和双击，并确认设备显示了正确页面。
5. 检查 Clip 启动/停止、录音保留、Track 控件、Scene 启动以及当前小节 Scene Stop。
6. 在多轨 Arm/录音负载下观察灯光，确认动画稳定并跟随速度。
7. 延长连接时间，检查 App 退出/重启、断连或持续帧错误。

## 停止条件

如果 Mystrix 重启或 Launch 退出、MIDI 断开、错误 Clip 响应、录音内容消失、意外 Clip 被停止、页面灯位明显错误，或 Live 持续报告 NACK/超时，请停止测试。记录时间，并保留移除私人信息后的相关日志。
