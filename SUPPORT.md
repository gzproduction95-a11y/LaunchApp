# Support

Use [GitHub Issues](https://github.com/gzproduction95-a11y/LaunchApp/issues) for reproducible bugs and feature requests.

For a bug report, include:
- LaunchApp release and whether the installed device and Live halves came from the same ZIP.
- Mystrix model and MatrixOS version.
- Ableton Live version and operating system.
- A short, exact sequence that reproduces the issue.
- Relevant Live or serial logs with account names, paths, and other private information removed.

Do not post credentials, private Live Sets, full user-library folders, or unredacted logs.

# 获取支持

可复现的问题和功能建议请通过 [GitHub Issues](https://github.com/gzproduction95-a11y/LaunchApp/issues) 提交。

报告问题时请提供：
- LaunchApp 发布版本，以及设备端和 Live 端是否来自同一个 ZIP。
- Mystrix 型号与 MatrixOS 版本。
- Ableton Live 和操作系统版本。
- 能准确复现问题的简短步骤。
- 移除账号名、个人路径等私人信息后的 Live 或串口日志。

不要发布凭据、私人 Live Set、完整用户音乐库目录或未清理的日志。
